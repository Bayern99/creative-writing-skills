# 给 Codex 子代理的写作简报

Muse 是与作者对话的当前会话。下列名称代表本次交办的工作。在当前宿主允许委派且任务需要独立判断时，使用宿主已有的子代理工具启动通用子代理，在简报中给出角色和任务。已有技能目录以当前安装实际解析的路径为准；将简报用到的[审读技能](../../story-review/SKILL.md)、[设定维护技能](../../story-memory/SKILL.md)或[文风资料](style-analysis.md)解析为安装目录中的绝对路径交给子代理。保留宿主的模型、推理强度、权限、审批与并发设置；在现有容量内分批。写同一场戏只设一个执笔人。

简报写明本轮的一个问题、稿本版本、目标读者效果、已定与试行的选择、允许阅读的最小材料、提交形式，以及唯一可写目标（如有）。优先给章节、样稿和设定的准确路径；给首次试读者和角色扮演者另开不继承对话的上下文，只传其视角可见的文本。若宿主不能隔离上下文，标注“带前情的模拟”。资料共享范围是工作约定，宿主的权限边界仍由当前会话决定。

| 角色 | 何时交办，给什么 | 返回给 Muse |
| --- | --- | --- |
| 构思者 / 角色扮演者 | 前者按不同角度探索同一个困局，附已否决选项；后者只拿当时人物的知识、关系和口吻样本 | 备选走向及代价，或一段当场说出的话。即兴结果保持试行状态 |
| 大纲师 | 作者已确认方向时给关键节点、人物状态及章节跨度 | 可起草的场景顺序、每场的转变、尚待决定的节点 |
| 执笔人 | 请求另一种写法、专门润色或稿幅需要独立上下文时；指定模式、场景、文风、上一场及正典约束 | 正文或唯一授权的稿件路径、影响含义的选择、与既有设定的冲突 |
| 文风整理 / 资料研究 | 文风整理读作者指定样本及 Muse 的 style-analysis.md；事实研究带具体疑问和假设，使用当前可用的来源 | 有出处的文风规律，或带来源、分歧与缺口的素材；由 Muse 决定如何采用 |
| 编辑 / 专项批评 | 读同包 story-review。一个人负责一个编辑层级或一个问题，给本版稿、创作目标，必要时给文风资料和前轮意见 | 按读者代价排序，定位文句，说明后果与修改方向；作为审读者只回报 |
| 连续性核查 | 读 story-review。常规检查可并入单次评读；跨章问题才专门交办。给本稿及其触及的定稿、时间线、术语或人物页 | 对照两端出处、严重性和覆盖边界；区分文本事实与人物说法 |
| 首次试读者 | 读 story-review 的首次试读方法。给读者画像和允许知道的章节；结局、编辑意见和作者笔记留在主会话 | 按阅读顺序说明何时相信、起疑或失去兴趣，并引出触发反应的文字 |
| 知识维护者 | 读同包 story-memory。给定稿、作者裁定、现有目标页；点明仍属试行的决定及允许的写入范围 | 带出处的增量、冲突、更新路径；重复归档时复用已有条目 |

发送互不依赖的审读任务后等待报告，再做依赖它们的修订、试读和归档。分别保存“提议”和“采纳”的判断。普通短段只做有价值的一遍；有多个独立风险的章节可并行，关键场景把名额给支撑其效果的维度。简报的差异提供不同视角；同模型的多次阅读不能作为跨模型验证。

子代理工具缺席、额度用尽、作者要求独自完成或某个子任务失败时，主会话用相同材料和交付约定逐项处理缺失的工作，指出哪些结果属于同一次会话。现有审读若已回答问题就直接采用。
