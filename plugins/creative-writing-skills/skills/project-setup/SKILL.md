# 建立小说工作区

读取并执行[上游 project-setup 方法](../../reference/skills/project-setup/SKILL.md)，其资源路径相对于该方法所在目录。使用具名角色或指定模型时，先遵循[模型与工具交接](../creative-writing-muse/references/writing-staffing.md)。按 [setup 角色](../../reference/agents/setup.md)在主会话完成访谈和作者确认。项目设置只读 other-harnesses.md 中的 Codex 部分。已安装这个分支时直接做访谈；安装来源与子代理调度按本插件说明。

1. 查看当前小说项目的 AGENTS.md、章节目录、设定集和作者指定的样稿。列出可以沿用的路径。已有项目按现有布局工作。
2. 只询问会改变设置的事项，例如哪份是正稿、哪里放试稿、要用谁的视角、哪篇样稿代表目标文风。没有样稿时记下作者自己描述的目标。
3. 在聊天中给出拟议的路径和 AGENTS.md 的简短增补，说明正稿位置、允许写入的草稿位置、设定来源和文风约定。对于新项目，可以从 story/（手稿）、work/drafts/（试稿）和 kb/（已定资料）开始。已有同类目录时直接复用。设定简单的短篇可以只用一个设定文件。
4. 作者确认后才创建约定好的目录和文件。合并已有约定，保留作者的原话。样稿可在原位引用；提炼文风时记录样稿出处。再次运行时先检查已有成果，只补这次确认的差异。
5. 列出实际创建或修改的路径，并告诉作者如何开始第一场。作者只想聊构思或贴一段试写时，可以直接使用 creative-writing-muse。
