# 让下一章找得到依据

先找项目已有的设定和章节索引，读与问题有关的条目。查设定时直接返回答案和出处。提议归档时先给出候选变更；作者明确要求更新时才写入项目约定的位置。

从定稿中摘出会约束后文的变化，例如某人何时知道真相、伤势出现在哪一侧、钥匙最后在谁手里。给每项附章节和场景、短引文或作者明确裁定的出处。区分人物所言、人物所信与叙事已经证实的事实。一句台词可以证明“她这样说过”，其内容的真伪需要另外的依据。

试写、备选动机和“暂时先这样”的意见保留为待定项；作者明确要求保存备选时，放在项目的工作笔记。记录已经确认的部分时，以原有的人物页、时间线或术语表为准，修改最贴近的现有条目。同一材料再次归档时先比对，合并相同事实。发现两份定稿冲突时保留两边的章节出处，请作者裁定；其余可核实的更新照常进行。

交付时列出有变化的条目和文件，将仍需裁定的具体问题单列。若没有新增事实，直接说明。
